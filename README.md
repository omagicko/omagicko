Sou Luiz Henrik, desenvolvedor em formação e pesquisador/estudante de Cibersegurança, com interesses que conectam **engenharia de software, segurança da informação e inteligência de fontes abertas (OSINT)**.

Na área de desenvolvimento, estudo a construção de APIs e aplicações backend com Node.js, TypeScript, SQL e AdonisJS, além do desenvolvimento mobile com React Native.

Na área de segurança, direciono meus estudos para OSINT, Pentest, segurança da informação, Android Hacking, Hardware Hacking e Bug Bounty. Busco compreender como aplicações e sistemas são construídos, como podem apresentar vulnerabilidades e como melhorar sua segurança.

Este GitHub reúne meus projetos, laboratórios autorizados, estudos, documentação técnica e evolução prática.

## About me

I'm Luiz Henrik, a software development learner and cybersecurity researcher/student interested in the intersection of **software engineering, information security, and Open Source Intelligence (OSINT)**.

On the development side, I study backend APIs and applications using Node.js, TypeScript, SQL, and AdonisJS, as well as mobile development with React Native.

On the security side, my learning focuses on OSINT, penetration testing, information security, Android Hacking, Hardware Hacking, and Bug Bounty. I aim to understand how applications and systems are built, how vulnerabilities can occur, and how their security can be improved.

This GitHub profile brings together my projects, authorized labs, technical studies, documentation, and practical learning journey.

### Areas of interest

- **Backend:** Node.js, TypeScript, SQL, REST APIs, and AdonisJS.
- **Mobile:** React Native, NativeWind, Reanimated, camera, location, and authentication.
- **Cybersecurity:** Information Security, penetration testing, and vulnerability assessment.
- **OSINT:** research, collection, correlation, and analysis of open-source information.
- **Mobile Security:** Android security studies.
- **Hardware Security:** hardware-related security fundamentals and research.
- **Bug Bounty:** vulnerability identification, analysis, and responsible reporting fundamentals.
